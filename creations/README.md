# Créations hors flux

Déposer ici `<nom>.json` (minuscules, chiffres, tirets) au format décrit dans `scripts/build_episode.py`.
Le workflow « Fabriquer une création » publie `docs/creations/<nom>.mp3`, listé sur
`https://martinparnin-svg.github.io/revue-du-matin/creations/`, sans toucher au flux podcast.

**Public** : GitHub Pages est accessible à tous. Aucun contenu personnel ici.
